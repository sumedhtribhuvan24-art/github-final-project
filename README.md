# Simple Interest Calculator

## Project Description

This project is a simple interest calculator implemented using a Bash script. It calculates simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

* Principal amount
* Annual rate of interest
* Time period in years

## Usage

Run the `simple-interest.sh` script in a Bash-compatible terminal and enter the requested values.

## Example

For a principal of 1000, an annual interest rate of 5%, and a period of 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
